원어민 친구 에이전트 사용자 요구사항:

Seamless Smart-Glass / Earphone UI 상태 전환

화면을 터치하거나 별도의 버튼을 누르지 않아도 ChatGPT의 말하기 UI처럼 음성 상태를 자동으로 인식하고, Ready → Listening → Speaking → Ready (→ Capturing: 말로 제어) 모드가 자연스럽게 전환된다. 이를 통해 스마트글라스 환경에서도 완전한 핸즈프리(hands-free) 대화가 가능해야 한다.

스마트글라스에서는 현재 상태와 대화 텍스트를 화면에 표시하고, 이어폰에서는 음성 안내나 효과음으로 상태를 전달한다.

실전 회화 중심의 영어 대화

ChatGPT가 매번 새롭고 다양한 주제로 대화를 시작한다. (매번 오늘 어때 같은 내용이 아닌..)

반복적인 질문은 피하고, 사용자가 흥미를 느낄 수 있도록 대화를 주도한다.

실시간 영어 교정(Recast) 및 표현 학습

사용자가 영어로 말하면, 먼저 더 자연스럽고 원어민다운 표현으로 recast한다.

사용자가 한국어로 말하거나 영어 번역을 요청하면 자연스러운 영어 문장으로 바꾸어 준다.

사용자가 요청하지 않는한, 나를 따라하시오, 라고 요청하지 않는다.

하루의 핵심 학습 표현을 사용자 메모리에 저장

하루의 대화가 끝날 때 **“오늘 내가 배워야 할 표현”**을 자동으로 선별하고 저장한다.

저장 대상은 다음과 같다.

사용자의 원래 표현보다 확실히 더 자연스럽고 수준 높은 recast 표현

사용자가 한국어 표현의 영어 번역을 요청했을 때 제공된 유용한 문장

예:

The most captivating feature is the lush greenery outside the windows.

After all the painstaking effort, my weight drops just a tiny bit, but when it goes up, it skyrockets in an instant.

단순히 문법만 조금 수정한 표현은 제외하고, 실제로 다시 사용할 가치가 높은 표현만 저장한다.
