# 한국어 Whisper 실측과 부스 진행자 대본 — 2026-09-26

## 1. 실측: Whisper 가 한국어 오류를 살리나

ELLA 에서는 Whisper 가 영어 오류를 지웠다 (`goed → go` 100%, 규칙동사 현재형만 생존). 한국어에서도
같은 일이 벌어지면 부스에서 튜터가 고칠 오류가 없다. 그래서 오류 유형별로 쟀다.

**방법.** 앱이 쓰는 것과 같은 모델(`whisper-1`)·언어(`ko`)·프롬프트로 `/v1/audio/transcriptions` 를
직접 호출. 음성은 macOS `Yuna` 합성. 옛 프롬프트("한국어 학습자와의 회화 연습.")와 새 프롬프트
(`OpenAiRealtimeTransport.TRANSCRIPTION_PROMPT`, 들리는 대로 적으라는 지시)를 나란히.

| 오류 유형 | 원문 | 옛 프롬프트 | 새 프롬프트 |
|---|---|---|---|
| 목적어에 주격 조사 | 어제 친구가 만났어요 | 어제 친구가 만났어요 | 어제 친구가 만났어요 |
| 시제 (내일+과거) | 내일 학교에 갔어요 | 내일 학교에 갔어요 | 내일 학교에 갔어요 |
| 목적어에 주격 조사 | 저는 밥이 먹었어요 | 저는 밥이 먹었어요 | 저는 밥이 먹었어요 |
| 여격 대신 목적격 | 친구를 전화했어요 | 친구를 전화했어요 | 친구를 전화했어요 |
| 시제 (지금+과거) | 지금 책을 읽었어요 | 지금 책을 읽었어요 | 지금 책을 읽었어요 |
| 높임 불일치 | 선생님이 저한테 말했다 | 선생님이 저한테 말했다 | 선생님이 저한테 말했다 |
| 목적어에 주격 조사 | 제가 어제 영화가 봤어요 | 제가 어제 영화가 봤어요 | 제가 어제 영화가 봤어요 |
| 청유형 어미 오류 | 우리 같이 밥 먹자요 | 우리 같이 밥 먹자요 | 우리 같이 밥 먹자요 |

**결과: 8/8 생존, 두 프롬프트 모두.** 영어와 정반대다. 한국어 Whisper 는 조사·시제·어미·높임
오류를 정규화하지 않았다.

**단서.** 합성 음성은 발음이 또렷하다. 사람 발음, 특히 외국인 학습자의 발음에서는 Whisper 가
더 많이 "고칠" 수 있다. 부스 전에 사람 목소리로 한 번 더 재는 것이 맞다 — 아래 §3.

**안경 마이크 실측은 못 했다.** 맥 스피커로 안경에 들려주려 했으나 VAD 가 한 번도 열리지 않았다
(최대 볼륨에서도 `speech_started` 없음). 안경과 맥의 물리적 배치 문제라 이 세션에서 해결 불가.
DEBUG_EVENT 주입 경로(전사 → 진단 → 해제)는 실기기에서 전부 검증됐다 (`e6a464c`).

## 2. 진단·해제 실측 (실기기, DEBUG_EVENT 주입)

```
오류 3턴   어제 친구가 만났어요 / 오늘 아침에 빵이 먹었어요 / 내일 영화가 볼 거예요
           → grammar 3건 기록 (친구가→친구를, 빵이→빵을, 영화가→영화를)
           → 3턴째 consolidate → ruleGap "목적어에 주격 조사를 씀: 을/를 대신 이/가"
           → practiceTargets 친구를 만났어요 · 빵을 먹었어요 · 영화를 볼 거예요
           → 우상단 "coach luna"                      [indicator-lit.png]

정답 3턴   어제 친구를 만났어요 / 오늘 아침에 빵을 먹었어요 / 내일 영화를 볼 거예요
           → 6턴째 consolidate → ruleGap null
           → 우상단 "coach ·"                          [indicator-cleared.png]
```

## 2b. 2세대 실기기 검증 (아키텍트 리뷰 후)

```
혼합 오류 3턴 (조사/시제/높임)   → grammar 3건, ruleGap null    [learner-state-mixed-errors-no-diagnosis.json]
                                 모델이 패턴을 지어내지 않는다
재시작 (--reset 없이)            → ruleGap 유지, 부팅 직후 coach luna   [indicator-after-relaunch.png]
                                 turnId 가 4·5·6 으로 이어지고 6턴째 해제
코드스위칭 게이트               → "저는 Jennifer예요" 통과 · "I said 안녕하세요 to her" 차단
                                 "busy한 하루였어요" 통과 · "あああ" 차단   [learner-state-gate-codeswitch.json]
정답 1턴                        → 진단 유지 (3턴 정답이어야 해제)
일본어 소음 2턴                 → 기록도, 해제 카운트도 안 됨
```

## 3. 부스 진행자 대본 — 관람객이 실수를 안 할 때

**같은 유형을 세 번** 말해야 진단이 뜬다. 목적어 조사 오류가 가장 확실하다 — 실측에서 3/3 잡혔고,
한국어 학습자가 실제로 가장 많이 하는 실수다.

```
① "어제 친구가 만났어요."           (친구를)
② "오늘 아침에 빵이 먹었어요."      (빵을)
③ "내일 영화가 볼 거예요."          (영화를)
   → 여기서 우상단이 coach · 에서 coach luna 로 바뀐다. 손으로 가리킨다.
   "지금 뒤에서 느린 모델이 습관을 잡았어요. 목적어에 주격 조사를 쓰는 습관."

④ "어제 친구를 만났어요."
⑤ "오늘 아침에 빵을 먹었어요."
⑥ "내일 영화를 볼 거예요."
   → coach luna 가 coach · 로 돌아간다.
   "학습자가 나아지니 진단이 스스로 꺼졌습니다."
```

**한 문장에 오류 하나씩, 천천히, 또렷하게.** 각 턴 사이 12초 이상 — 느린 계층이 돌 시간.

**관람객이 바뀌면 `ops/launch-lumella.sh --reset`.** 안 하면 앞사람의 진단이 다음 사람에게 붙는다
(진단은 재시작을 견디도록 만들어져 있다 — 그게 의도다).

**부스 전 확인.** 위 여섯 문장을 **사람 목소리로** 안경에 직접 말해 `learner-state.json` 에
`grammarErrors` 가 3건 쌓이는지 본다. 합성 음성 실측(§1)이 사람 발음에서도 성립하는지는
그때 확정된다.
